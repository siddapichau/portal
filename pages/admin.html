🔗 Planilhas por Página

Cada página do portal pode usar a planilha dela. Cole abaixo a URL /exec do Apps Script publicado daquela planilha. Páginas sem URL continuam usando a planilha central (a do cérebro: menu, usuários, notícias…).

Definida em js/portal-db.js → PortalDB.URL. Usada por menu, login, usuários, mural, status e logs.
Formato aceito: https://script.google.com/macros/s/AKfy.../exec — implante como Aplicativo da Web com acesso “Qualquer pessoa”. Depois de salvar, use Versão / Cache para todos receberem a mudança na hora.

🔄 Versão e Cache Global

Publicou uma mudança e ela não aparece para os outros? Suba a versão aqui: todas as páginas do portal limpam o cache sozinhas na próxima visita, mantendo o login.

🚀 Publicar nova versão

🧹 O que é limpo

  • Todo o cache de dados (menu, usuários, notícias, status, logs, cargos…)
  • Cache visual das páginas e preferências temporárias
  • URLs de planilhas em cache (são recarregadas da planilha central)
Nunca é apagado: login, avatar e o tema claro/escuro.

📖 Como usar

  • Fez mudanças em CSS, JS, menu ou numa página? Clique em ⚡ Gerar automática.
  • Depois em 💾 Salvar e limpar cache global.
  • Cada usuário detecta a nova versão em até 30 segundos (ou ao abrir o portal), limpa o cache e recarrega sozinho — sem deslogar.
Use com moderação: cada troca de versão faz todos recarregarem e refazerem as consultas na planilha.
